## ✦ Como Utilizar

Estes identificadores `DS` correspondem exatamente às edições numeradas no arquivo `Denzinger-Compendio-Fe-e-Moral.pdf`. Ao inspecionar uma prova no sistema web ou via Prolog, consulte os números de Denzinger para validar o texto oficial em latim/português do Magistério.
